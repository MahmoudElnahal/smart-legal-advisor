# المستشار القانوني الذكي — وزارة العمل المصرية

منظومة استشارات قانونية ذكية بالعربية، مبنية على **قانون العمل الجديد رقم 14 لسنة 2025** والقرارات الوزارية التنفيذية. تدعم المحادثة النصية والمكالمة الصوتية التفاعلية المباشرة.

---

## المتطلبات

- **Node.js** 18 أو أحدث
- **مفتاح Gemini API** — تقدر تجيبه من [Google AI Studio](https://aistudio.google.com/apikey)

---

## التشغيل

### 1. تثبيت الحزم
```bash
npm install
```

### 2. إعداد مفتاح الـ API
اعمل ملف `.env.local` في جذر المشروع وحط فيه:
```
GEMINI_API_KEY=المفتاح_بتاعك_هنا
```
> الملف ده متجاهَل في git تلقائياً، فمفتاحك مش هيترفع.

### 3. تشغيل سيرفر التطوير
```bash
npm run dev
```
افتح المتصفح على **http://localhost:3000**

## المميزات

### المحادثة النصية
واجهة شات عربية (RTL) بترد على الاستفسارات القانونية مع عرض مواد القانون المرجعية لكل إجابة.

### المكالمة الصوتية
مكالمة تفاعلية مباشرة — المستخدم بيتكلم والنظام بيرد صوتياً. بتحتاج إذن الميكروفون من المتصفح.

### سلسلة نماذج احتياطية
الخدمة بتجرّب أكتر من نموذج Gemini بالترتيب مع إعادة محاولة تلقائية، عشان تفضل شغالة حتى وقت الضغط على الخوادم:

```
gemini-3.8-flash  →  gemini-flash-latest  →  gemini-3.1-flash-lite
```

بتتعامل تلقائياً مع أخطاء `503` (ضغط مؤقت) و `429` (تجاوز الحصة). ولو كل النماذج فشلت، فيه رد احتياطي مبني على قاعدة المعرفة المحلية بدل ما المستخدم يشوف رسالة خطأ.

## بنية المشروع

```
├── App.tsx                        نقطة الدخول
├── constants.ts                   نص القانون + الأسئلة الشائعة + القرارات الوزارية
├── types.ts                       تعريفات TypeScript
├── vite.config.ts                 إعدادات Vite + بروكسي التحويل الصوتي
│
├── components/
│   ├── ChatView.tsx               واجهة المحادثة النصية
│   ├── Layout.tsx                 الهيكل العام والتنقل
│   ├── LegalMessageRenderer.tsx   عرض الردود القانونية ومواد القانون
│   ├── MinistryLogo.tsx           شعار الوزارة
│   └── VoiceCallModal.tsx         واجهة المكالمة الصوتية
│
└── services/
    ├── geminiService.ts           الاتصال بـ Gemini + النماذج الاحتياطية
    └── speechService.ts           النطق العربي وتحويل الأرقام لكلمات
```

### قاعدة المعرفة
`constants.ts` هو مصدر الحقيقة القانوني. فيه:

| التصدير | المحتوى |
|---|---|
| `LAW_CONTEXT` | نص أحكام قانون العمل 14/2025 |
| `FAQS` | الأسئلة الشائعة وإجاباتها |
| `LEGAL_TOPICS` | تصنيفات المواضيع القانونية |
| `MINISTERIAL_DECREES_HIGHLIGHTS` | أبرز القرارات الوزارية التنفيذية |

المحتوى ده بيتحقن في الـ system instruction بتاع Gemini، فأي تعديل قانوني بيتعمل هنا — مش في الـ prompts.

## ملاحظات

**أمان المفتاح:** المفتاح بيتحقن في الـ bundle بتاع الـ frontend وقت البناء (شوف `define` في `vite.config.ts`)، يعني أي حد يفتح الموقع يقدر يستخرجه. ده مناسب للتطوير المحلي، لكن **قبل النشر العام** لازم تنقل نداءات Gemini لسيرفر خلفي والمفتاح يفضل عليه.

**النطق العربي:** فيه بروكسي في `vite.config.ts` على `/api/tts` بيستخدم خدمة النطق من Google كبديل لما صوت المتصفح العربي ميكونش متاح. البروكسي ده شغال في `dev` و `preview` بس — لو نشرت الملفات الثابتة لوحدها، المسار ده مش هيشتغل.

**إخلاء مسؤولية:** النظام أداة إرشادية ومش بديل عن الاستشارة القانونية الرسمية.
